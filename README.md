## 📖 About PDFtoMusic

PDFtoMusic is a macOS and Windows tool that recognizes musical scores in PDF files and converts them to playable MIDI or MusicXML format. It allows musicians to hear and edit scores distributed as PDF sheet music without manual re-entry.
